# LCPS Bowl correction pack

1. Unzip this pack into the existing LCPS Bowl project folder.
2. Open Claude Code in that project.
3. Paste the complete contents of `START_HERE_Claude_Prompt.md`, or ask Claude Code to read that file and implement it.
4. Keep the gear, logos, guide, style reference and tech pack alongside the prompt. A prompt alone cannot supply image bytes.

Includes the eight exact supplied gear images, character motion guide, original character reference, current animation tech pack, and 17 official school logo files.

## Logo sources and limitations

Each logo was downloaded from its school's official LCPS home-page header on October 4, 2026. `logo-manifest.json` records the exact school page and original image URL for every file. These are school logos/lockups, not a claim that every image is an isolated athletic mark or the exact decal currently worn on football helmets. The included full logos have been visually inspected for the correct school identity.

Several linked athletics sites returned access-denied responses. This pack uses the available official school-site artwork, without bypassing those restrictions. If you prefer a particular secondary sports logo or an exact helmet decal, supply that verified variant and explicitly tell Claude to replace it. Do not let Claude invent one.

The images remain the property of their respective owners. This pack does not confer permission or imply school/equipment-brand endorsement.

## Animation guide

The motion guide is concept art showing key poses, not a production-ready registered atlas. The tech pack specifies all actions, frame counts, timing, directions, builds and attachment rules. Claude must still implement those animations and their gameplay states.

## Exact equipment files

The four pad files use the `(1)` versions. The four helmet files use their original UUID filenames. Shop art should remain unchanged; lower-resolution gameplay variants should preserve each model's recognizable shape.

`SHA256SUMS.txt` allows imported files to be checked against this pack. Do not use unrelated generated helmets/pads or fabricated logos as fallbacks.
