# Baseball audio assets

Drop audio files here to replace the built-in synthesized placeholder sounds. Files are loaded
by name (first match wins: `.mp3`, then `.ogg`, then `.wav`):

| File name            | When it plays                         |
| -------------------- | ------------------------------------- |
| `batCrack`           | Normal contact                        |
| `batCrackBig`        | Barreled / hard contact               |
| `glove`              | Ball hitting a glove / catcher's mitt |
| `crowdAmbience`      | Looping crowd bed                     |
| `crowdCheer`         | Crowd reaction (hit, strikeout, run)  |
| `crowdGroan`         | Crowd disappointment                  |
| `crowdRoar`          | Home run                              |
| `strikeCall`         | Umpire strike call                    |
| `ballCall`           | Umpire ball call                      |
| `outCall`            | Umpire out call                       |
| `safeCall`           | Umpire safe call                      |
| `slide`              | Runner sliding                        |
| `swing`              | Bat whoosh                            |
| `pitch`              | Pitch release whoosh                  |
| `organ`              | Between-innings organ sting           |

Example: `public/baseball/audio/batCrack.mp3`.
